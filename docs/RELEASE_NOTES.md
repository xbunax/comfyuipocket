ComfyUI Pocket v0.17.9

- Share locally stored ComfyUI node definitions between the parameter editor and the canvas. Pocket plugin 0.12.0 validates the revision and sends changed or removed definitions when it has the matching base revision.
- Revalidate frontend and extension scripts individually with WebKit's HTTP cache. Use plugin 0.12.0 to enable this with ComfyUI.
- Reuse the minimap's node bitmap when only the canvas viewport changes.
