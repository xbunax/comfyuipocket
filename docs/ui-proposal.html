整套 App 的布局方案

工作台 / 工作流

顶部只保留搜索与新建。置顶单独成组；工作流卡片显示名称、类型、同步状态。按偏好直接进入画布或参数。

画布 / 节点导航

紧凑硬件条，右上主运行按钮。底部为总览、节点轮盘、收藏、工具；大屏使用侧栏，编辑文字时自动避让键盘。

参数 / 提示词

保留宽输入框及词块开关。编辑模式进入专页，管理权重与翻译。分辨率左右并排；批量滑块与随机种子在同一区域。

任务

当前批次置顶，进度、数量和缩略图形成一个任务卡。历史任务使用紧凑行；详情展示每次生成的参数与产物。

作品 / Output

统一来源切换、排序和布局入口。任务产物默认折叠成组；文件夹和图片共用列表/平铺。预览页以作品为主，信息抽屉为辅。

连接 / 设置

IP 与 P2P 在同一分栏中选择。连接结果集中显示，设置承接外观、默认视图、缓存和布局偏好。错误直接给出可操作原因。
